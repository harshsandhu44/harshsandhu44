## The problem

In a house with pets, care is shared, and shared tasks get done zero times or twice. "Did anyone already feed Milo?" gets asked in the group chat every morning.

furbaby board is a shared list of what's due today. You set the routine once: breakfast at 07:00, a walk at 08:30, thyroid meds at noon. Everyone in the household sees the same board, and each tick is signed with a name and a time. Care history builds up as a side effect.

## What I built

- **A Next.js web app** with the board, pets, household and plan screens, onboarding, and a printable care sheet for each pet.
- **An Android app** in Expo that talks to the same REST API and sends push reminders.
- **Pet records**: weights, vet visits, a 14-day grid of done, skipped and missed items, and minimum spacing between doses of a medicine.
- **Reminders** sent as web and mobile push by a scheduled worker every fifteen minutes.
- **An MCP server** so AI assistants can read the board and tick things off, and **an Alexa skill** so "Alexa, I fed Milo" works with your hands full.
- **Subscriptions** on two payment rails: Razorpay on the web and Google Play in the app.

## Key decisions

### Expand recurrence at read time

Routines store a recurrence rule and a clock time, and today's list is computed on every request. Nothing needs backfilling, and because the expansion only deals in dates, 07:00 stays 07:00 across daylight-saving changes. The 14-day history replays the rule backwards, so a missed day can be told apart from a day the routine never ran, without storing anything extra.

### Let the database settle races

A unique index on routine and date means that if two people tap the same item at the same moment, the second one is told who got there first. No double feeds, enforced by the database rather than by hoping the UI stays in sync.

### One rule, every client

The web app, the mobile API, the MCP tools and the Alexa skill all call the same functions. Household ownership checks and the no-double-tick rule are written once. Where a client can't be sure which household you mean (an assistant token belongs to a person, not a household), the tools refuse rather than guess.

### Voice should ask when it isn't sure

"I fed Milo" ticks the item closest to now. If two doses are outstanding, Alexa asks which one, because a wrong tick would shift the spacing of the next dose.
